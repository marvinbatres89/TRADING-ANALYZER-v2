# Trading Analyzer Pro — Módulo 1 V2

## Estructura obligatoria

TRADING-ANALYZER-v2/
├── index.html
├── style.css
├── README.md
└── js/
    ├── app.js
    └── connection.js

## Importante

`app.js` y `connection.js` deben estar dentro de la carpeta `js`.

Esta versión evita `type="module"` para mejorar la compatibilidad con navegadores móviles, pero conserva la organización profesional por archivos.

## Prueba

1. Abre GitHub Pages.
2. En Diagnóstico debe aparecer: `JavaScript: Activo`.
3. Pulsa Conectar.
4. Si no llegan precios, pulsa Copiar y envía el diagnóstico.
